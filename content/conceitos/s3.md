## O problema que resolve

Armazenar objetos como documentação estática.

## Como funciona

S3 é o serviço; bucket organiza objetos; chave identifica um objeto no bucket. Conhecer o endereço não concede permissão.

## No fluxo de entrega

Publicador autorizado grava os arquivos; backend autorizado pode ler para servir documentação.

## Exemplo

Trecho didático; não é um arquivo completo.

```text
s3://bucket-exemplo/default/component/portal/index.html
```

## Como verificar

Valide escrita, leitura e bloqueio de acesso não autorizado.

## Objetivo

Um espaço para resolver demandas de estudo e documentar o que aprendemos. Cada laboratório apresenta um contexto, um resultado esperado e condições que exigem investigação. Os comandos e ferramentas são usados para chegar a essa entrega.

## Passo a passo

Escolha uma demanda no catálogo. Na própria página estão os pré-requisitos, acessos, cenário e critérios. As tags indicam os conhecimentos exercitados; os laboratórios ficam separados do mapa de conceitos.

Adapte o enunciado ao seu projeto usando **Editar laboratório**. Quando houver algo para relatar, o editor permite acrescentar uma seção de resolução; nenhum formulário vazio é publicado junto do enunciado.

### Espaços de estudo

[Organização Jardim de Plataforma](https://github.com/jardim-plataforma) · [Repositórios de estudo](https://github.com/jardim-plataforma?tab=repositories) · [Docker Hub](https://hub.docker.com/)

Cada demanda tem um repositório próprio na organização. O enunciado informa o nome e o ponto de partida; os repositórios guardam implementação, PRs e evidências. GitLab permanece como comparação de conceitos, sem execução paralela obrigatória. Os endereços podem ser editados aqui.

## Como verificar

Cada demanda informa o que caracteriza uma entrega concluída. O resultado precisa demonstrar funcionamento, decisões e recuperação quando aplicável; uma sequência de comandos executados, sozinha, não basta.
